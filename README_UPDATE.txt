COPKU v1.38 — UPDATE ONLY (base v1.37)

Fixes one separator between discussion replies, removes the floating
Try portal demo link from the official homepage, and prevents demo portal
files from being included in future official release ZIPs.

1. Extract this ZIP.
2. Copy its contents into your existing COMPLETE website folder. Keep the
   folder paths, replace matching files and keep all other website files.
3. If that folder has a portal-preview folder, delete portal-preview from
   the copy you deploy to the official site. The real portal/internal folder
   must be kept.
4. Upload the resulting COMPLETE folder to your existing Netlify website.
   This small update ZIP alone is not a complete website.
5. Refresh with Ctrl+Shift+R (Windows) / Command+Shift+R (Mac) if needed.

No Supabase, Stripe, Brevo or email changes are required.
See UPDATE_FROM_v1.37.md for details.
